# jade-archive
локальная CRM-система для управления социальным графом и персональными досье. Приложение позволяет создавать иерархическую структуру контактов, отслеживать связи между людьми, хранить расширенную информацию о каждом человеке (медицинские данные, документы, предпочтения) и управлять делами/проектами.
